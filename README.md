# AD450 Coffee Exploration

This project explores coffee export, import, and production datasets using Python and Pandas.

## Files

- coffee\_exploration.ipynb \- Jupyter notebook containing the analysis
- Coffee\_export.csv \- Coffee export dataset
- Coffee\_import.csv \- Coffee import dataset
- Coffee\_production.csv \- Coffee production dataset
- pyproject.toml \- Project configuration and dependencies
- uv.lock \- Locked dependency versions

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- uv
